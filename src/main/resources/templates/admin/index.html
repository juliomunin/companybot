Mining

Web mining é a integração de informações coletadas por técnicas tradicionais com informações coletadas na Web. A mineração na Web pode ser usada para entender o comportamento do cliente, ajudar a quantificar o sucesso de uma campanha de marketing ou gerar dados para estudos comerciais.

Robotic Process
Automation

RPA, ou Automação de Processos, possibilita a integração de sistemas de forma a trocar informações sem que seja necessário a construção de uma interface entre eles. Ou seja, ele captura qualquer informação, em qualquer site ou aplicação, navegando como se fosse um usuário comum.
